# Ufuk Yılmaz - Kişisel Portfolyo Web Sitesi

Bu portfolyo; Yapay Zekâ, Uçta Yapay Zekâ (Edge AI), Bilgisayarlı Görü ve Büyük Dil Modelleri (LLMs) alanlarındaki deneyimlerinizi, projelerinizi ve yeteneklerinizi sergilemek üzere modern **HTML5 + Tailwind CSS** kullanılarak hazırlanmıştır.

---

## 🚀 GitHub Pages Üzerinde Ücretsiz Yayınlama (2 Dakika)

Portfolyonuzu tüm dünyanın erişebileceği `https://ufuktr08.github.io` adresinde canlıya almak için:

1. **GitHub'da Yeni Repo Oluşturun:**
   - GitHub hesabınıza giriş yapın.
   - Yeni bir repository (depo) açın ve adını tam olarak şunu yapın:  
     `UFUKtr08.github.io` (Public olarak işaretleyin).

2. **Dosyaları Yükleyin:**
   - Bu klasör içindeki (`portfolio/`):
     - `index.html`
     - `Ufuk_Yilmaz_CV_TR.pdf`
     dosyalarını oluşturduğunuz depoya sürükleyip bırakın (veya `git push` yapın).

3. **Yayınlandı!**
   - GitHub 1-2 dakika içinde sitenizi `https://ufuktr08.github.io` adresinde otomatik olarak yayına alacaktır.
